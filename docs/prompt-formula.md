# The prompt formula

A Muse avatar prompt passes when it describes a concrete character, outfit and setting in plain language, with no weapon, no real person and no trademarked character.

## The formula

1. **Character.** A defined face: eyes, hair, lips, expression. The same definition every time, so the avatar stays recognisably the same person.
2. **Outfit.** A named garment: type, neckline, length, fabric, colour. A brief with no garment lets the generator fill the gap and cross the line.
3. **Setting.** A plain place and a plain situation.
4. **Rendering.** Photorealistic, a real person. Never a cartoon look.
5. **Change.** One element at a time from the last look that worked. Record pass or fail before the next step.

## The shape

Use a well-proportioned hourglass figure with long legs. Never leave the shape as "perfect" or "beautiful" with no definition. Never name the bust size in the brief, and never request a bigger bust as a standalone change. A different body type needs a new avatar, because an outfit edit preserves the body.

## Length

Move a length one step at a time. Floor length becomes knee length, knee length becomes a mini dress well above the knee. Never write "shortest possible" — that gets refused. A mini dress is the shortest the generator allows.

## Face and body changes

An outfit edit preserves identity by design, so it returns the same face and the same body. A face or body change needs a fresh create, and a realistic new face needs a reference photo: a plain portrait or a clothed full-body photo. A lingerie cover or an adult-framed photo is not suitable.

## Worked example

Raw request:

```
Make her stunning, and make the dress shorter and sexier.
```

Polished brief:

```
A woman with long wavy blonde hair and a warm smile, a well-proportioned hourglass figure with long legs, wearing a black satin slip mini dress with a plunging neckline and strappy heels, photorealistic.
```

Tested 6 Nov 2026. The raw request was vague and unusable. The polished brief names the face, the shape, the garment and the rendering, and changes one thing: the dress, one length step down with one bolder element.
